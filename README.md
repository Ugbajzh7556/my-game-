# my-game-

## استخدام وكيل ذكاء اصطناعي للهندسة العكسية

هذا المستودع جاهز لإرشاد وكيل برمجي يعمل على المشروع كله واستخدام **REA** عبر MCP لتحليل تطبيق أو موقع تملك حق تحليله، ثم تنفيذ إعادة بناء نظيفة داخل المستودع.

- تعليمات الوكلاء: [`AGENTS.md`](AGENTS.md)
- خطوات الإعداد: [`docs/AI_SETUP.md`](docs/AI_SETUP.md)
- REA: <https://github.com/morluto/rea>
- قائمة واجهات LLM المجانية: <https://github.com/mnfst/awesome-free-llm-apis>

ابدأ من جهاز تشغيل الوكيل وثبّت Node.js بإصدار يدعمه REA، ثم نفّذ:

```bash
npx rea-agents@latest setup
```

اختر وكيلك في خطوات الإعداد ووافق على تسجيل MCP، ثم أعد تشغيل الوكيل وافتح جذر هذا المستودع معه. اختر مزوّد LLM من القائمة واضبط مفتاحه في إعدادات الوكيل الآمنة؛ لا تضع المفاتيح في ملفات Git.

> مستودع `awesome-free-llm-apis` فهرس لمزوّدين، وليس خدمة API بحد ذاته. قد يتطلب المزوّد حسابًا ومفتاحًا، كما تتغير حدود الخطة المجانية وشروط الخصوصية بمرور الوقت.
